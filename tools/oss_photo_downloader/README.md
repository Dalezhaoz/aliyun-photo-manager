# 阿里云 OSS 照片下载工具（Windows）

## 首次安装

1. 安装 Python 3.10 或更新版本，并在安装时勾选 **Add Python to PATH**。
2. 在本文件夹空白处按住 Shift 并单击鼠标右键，选择“在终端中打开”。执行：

```bat
py -3 -m pip install -r requirements.txt
```

3. 双击 `启动程序.bat`。

## 表格要求

- 支持 `.xlsx`、`.xlsm`、`.csv`，首行必须为列名。
- 在界面中自行选择“身份证号列”和“归档文件夹列”，不固定列名。
- 身份证号请在 Excel 中设为“文本”，避免 18 位号码被 Excel 改为科学计数法或丢失末位精度。

示例：

| 身份证号 | 地区 | 批次 |
| --- | --- | --- |
| 310101199001011234 | 上海市 | 第一批 |
| 110101199002022345 | 北京市 | 第二批 |

例如选择“地区”作归档文件夹列，结果将保存为：

```text
选择的下载目录/
  上海市/310101199001011234.jpg
  北京市/110101199002022345.jpg
  下载结果.csv
```

## OSS 对象规则

程序按以下规则寻找文件：

```text
对象前缀/身份证号.扩展名
```

例如对象实际路径是 `photos/2026/310101199001011234.jpg`：

- 对象前缀填写：`photos/2026`
- 照片扩展名填写：`.jpg,.jpeg,.png`

扩展名按填写顺序尝试。对象前缀为空时，程序直接尝试 `身份证号.jpg`。

程序使用 Python 内置的 OSS 签名下载，不再安装 `oss2` 与 `cryptography`，因此不会触发 Visual C++ / Rust 编译器错误，兼容 Windows ARM64 Python。

## 安全要求

- 推荐为该工具新建一个只具备目标 Bucket 读取权限的 RAM 用户，或使用短期 STS 临时凭证。
- AccessKey 不会保存到程序、Excel、日志或下载结果表中；关闭程序后即从内存清除。
- `下载结果.csv` 含身份证号，请与下载图片同样按个人信息进行管理。
