# 电话解密

## 功能目的

用于处理业务系统中的电话字段解密需求，减少人工导出和二次处理成本。

## 功能范围

- 支持电话字段解密处理
- 支持 Windows helper 辅助执行
- 支持打包进 Windows 发布产物

## 设计说明

- Python 主程序负责参数组织、页面交互和结果展示
- 具体解密依赖 Windows 环境下的 helper 与 DLL
- 打包时需要将 helper 和依赖 DLL 一并带入

## 发布注意事项

- 打包前检查 `Interop.DeDll.dll` 与 `DeDLL.dll`
- 打包前先执行 `build_phone_decrypt_helper.py`
- Windows 环境优先验证一次解密流程

- helper 自包含发布
