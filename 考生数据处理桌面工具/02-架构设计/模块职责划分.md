# 模块职责划分

## 设计原则

- GUI 不直接承载复杂业务规则
- 每个功能模块尽量只负责单一业务域
- 云存储、文件系统、模板解析尽量解耦

## 模块清单

- `app.py`
  照片下载与模板分类主流程编排
- `downloader.py`
  云存储与对象下载能力
- `excel_classifier.py`
  Excel 模板驱动的分类逻辑
- `certificate_filter.py`
  证件资料筛选与导出
- `word_to_html.py`
  Word/Excel 转 HTML
- `data_matcher.py`
  Excel 与 Excel 匹配补列
- `result_packer.py`
  压缩、AES 加密、历史记录查询
- `update_sql_generator.py`
  UPDATE SQL 生成与备份语句拼接
- `phone_decrypt.py`
  电话解密逻辑封装
- `id_card_tools.py`
  身份证号相关辅助处理
- `config.py`
  云存储配置与校验
- `gui.py` / `qt_gui.py`
  页面和交互入口

## 禁止混用的职责

- 不在 GUI 层内直接写复杂业务判断
- 不在下载模块里写业务分类规则
- 不在功能模块里耦合打包发布逻辑
