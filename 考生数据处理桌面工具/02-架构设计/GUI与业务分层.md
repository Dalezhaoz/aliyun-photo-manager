# GUI与业务分层

## 分层目标

- 页面代码负责交互，不承载复杂业务规则
- 业务模块负责处理规则，不直接依赖页面细节
- 打包发布逻辑与业务流程隔离

## 页面层职责

- 参数采集
- 页面切换
- 日志展示
- 进度展示
- 结果打开与复制

## 业务层职责

- 下载
- 分类
- 筛选
- 匹配
- SQL 生成
- 压缩加密
- 电话解密
- 身份证号处理

## 当前界面形态

- 传统 Tk 桌面入口：`gui.py`
- 新版 Qt 页面演进：`qt_gui.py` 与 `qt_ui/*`

## Dev 分支状态

`dev` 分支中，Qt 页面已经不只是壳层预留，而是进入“预览页齐备、逐页迁移”的阶段：

- 已有首页和导航体系
- 已有多工具页 Qt 版本
- 实验功能入口已纳入统一导航
