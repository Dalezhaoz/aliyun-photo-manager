# 总体架构

## 分层结构

系统整体分为三层：

- 界面层
- 业务层
- 基础设施层

## 界面层

负责：

- 页面布局
- 参数录入
- 任务触发
- 日志与结果展示

主要文件：

- `gui.py`
- `qt_gui.py`
- `src/aliyun_photo_manager/qt_ui/*`

## 业务层

负责：

- 照片下载与分类流程
- 证件资料筛选规则
- Excel 匹配规则
- SQL 生成规则
- 电话解密与身份证号处理逻辑

## 基础设施层

负责：

- 云存储连接
- Excel 读写
- 文件复制与重命名
- 压缩与加密
- Windows helper 调用
