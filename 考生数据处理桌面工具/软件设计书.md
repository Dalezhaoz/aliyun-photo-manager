# 软件设计书

## 1. 项目概述

考生数据处理桌面工具是一个面向考试报名、招聘资料交付与数据处理场景的 Python 桌面应用。系统围绕照片、证件、Excel、SQL、结果打包等核心业务提供统一 GUI 操作入口，并支持阿里云 OSS、腾讯云 COS 及本地目录三类数据来源。

当前设计基线版本为 `v2.1.0`。

## 2. 设计目标

- 支持大批量文件处理
- 保持 GUI 与业务逻辑分离
- 支持云存储扩展
- 支持结果可追溯与可交付
- 支持 Windows 桌面打包发布

## 3. 核心能力

- 照片下载与分类
- 证件资料筛选
- 表样转换
- 数据匹配
- 结果打包
- 更新 SQL 生成
- 电话解密
- 身份证号工具

## 4. 总体架构

系统采用“界面层 + 业务层 + 基础设施层”设计：

- 界面层：负责页面布局、输入采集、任务触发、结果展示
- 业务层：负责照片、证件、匹配、SQL、打包、解密等业务规则
- 基础设施层：负责云存储访问、Excel 读写、文件系统操作、打包、外部 helper 调用

## 5. 模块边界

主要模块如下：

- `app.py`：照片下载与模板分类主流程
- `downloader.py`：OSS/COS/本地文件来源访问
- `excel_classifier.py`：Excel 模板分类逻辑
- `certificate_filter.py`：证件资料筛选与导出
- `word_to_html.py`：表样转 HTML
- `data_matcher.py`：Excel 匹配补列
- `result_packer.py`：压缩加密与历史记录
- `update_sql_generator.py`：更新 SQL 生成
- `phone_decrypt.py`：电话解密能力
- `id_card_tools.py`：身份证号辅助能力
- `gui.py` / `qt_gui.py`：桌面入口与界面组织

## 6. 数据与输出

系统处理的核心对象包括：

- 照片文件
- 证件资料文件
- Excel 模板与结果文件
- SQL 脚本
- 压缩包及密码记录

典型输出包括：

- `照片分类模板.xlsx`
- `照片分类结果清单.xlsx`
- `证件资料筛选结果清单.xlsx`
- `*_数据匹配结果.xlsx`
- 更新 SQL 脚本
- 加密压缩包
